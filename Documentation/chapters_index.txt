PROJECT SUMMARY
---------------
This repository is a practical WebGL learning path covering canvas setup, geometry, primitive modes, shader data flow, dynamic buffers, screen-space math, and 2D transforms. The current project structure contains active examples through chapter 11 and a chapter 10 entry point used by the web demo.
