SCKORPIO WEBGL FUNDAMENTALS
==========================

Project overview
----------------
This repository is a practical learning path for WebGL 2.0 and shader-based graphics. The goal is to understand how the GPU pipeline works, how buffers and shader data flow, how geometry is built, and how transformations are used to render real-time visuals.

The examples are written in JavaScript and use the WebGL 2 API with GLSL ES 3.00.


CHAPTER 0
---------
chapter0.js
- Initial WebGL setup and reference code
- Basic shader boilerplate
- Early triangle example used as a starting template


CHAPTER 1 - Geometry Basics
---------------------------
Folder: chapter1/

chapter1a.js - Basic triangle
- WebGL canvas setup
- shader compilation and linking
- vertex buffer and vertex array object
- basic drawArrays() rendering

chapter1b.js - Multiple triangles
- multiple triangular shapes in a single draw call
- geometry layout and vertex reuse

chapter1c.js - Rectangle from triangles
- constructing a quad using two triangles
- understanding polygon creation

chapter1d.js - Index buffer introduction
- using an element array buffer
- drawElements() and vertex indexing

chapter1e.js - Complex geometry (letter F)
- building a custom shape from triangles
- reusing vertices and more advanced geometry composition

Focus: vertex data, primitive assembly, buffers, VAOs, and the basics of drawing geometry.


CHAPTER 2 - Primitive Topologies

Folder: chapter2/

chapter2a.js - POINTS

chapter2b.js - LINES
- simple line rendering
- parallel line patterns

chapter2c.js - Connected zig-zag lines
- line strips / chained vertex connections

chapter2d.js - LINE_LOOP
- repeated end-to-end connections
- closed line loop concept

chapter2e.js - Polygon / hexagon outline
- polygon-style line drawing

chapter2f.js - TRIANGLES
- triangle primitive topology

chapter2g.js - TRIANGLE_STRIP
- connected triangles sharing edges

chapter2h.js - TRIANGLE_FAN

Folder: chapter3/

chapter3a.js - Dynamic buffer / vertex manipulation

chapter3b.js - Dynamic buffer continuation

chapter3c.js - Additional topology-based experiments

chapter3d.js - More dynamic visual examples

CHAPTER 4 - Shader Data Flow
----------------------------
Folder: chapter4/

chapter4a.js - Uniform color

- controlling color from JavaScript

chapter4b.js - Varying color
- passing interpolated vertex data to the fragment shader

chapter4c.js - Multiple buffers
- separating position and color buffers

chapter4d.js - Combined buffer
- storing position and color together in one array

chapter4e.js - Varying + Uniform together
- combining per-vertex color and global uniform color

PROJECT SUMMARY
---------------
This project moves from the most basic WebGL concepts into more advanced renderer-like thinking:
- geometry creation
- primitive drawing modes
- GPU data flow
- uniforms and varying values
- dynamic updates
- transforms and animation

The repository is designed as a learning progression, leading toward a more complete understanding of graphics pipelines and renderer architecture.
