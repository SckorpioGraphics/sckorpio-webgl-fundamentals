SCKORPIO GRAPHICS — WEBGL FUNDAMENTALS
EPISODE PLAN AND IMPLEMENTATION STATUS
======================================

PURPOSE
-------
This file connects the planned teaching sequence to the code that actually
exists. Chapters 1–13 below are implemented in this repository. Chapters
14–23 are the forward plan and do not yet have lesson source files here.

The repository's implemented grouping is canonical: pixel/world work is
Chapter 8, camera is Chapter 9, and 2D object transformations continue through
Chapters 10–13 (translation, rotation, scale, and model matrices). Future
episode numbers continue from the implemented repository sequence.

IMPLEMENTED SERIES
==================

CHAPTER 1 — WEBGL BASICS AND TEMPLATE
-------------------------------------
1a. Raw first triangle: directly trace canvas, context, shaders, buffers, VAO,
	viewport, clear, and drawArrays.
1b. Lesson template: establish the code-section scaffold without rendering.
1c. Template-based triangle: fill the scaffold with a working triangle.

CHAPTER 2 — GEOMETRY AND INDEXING
---------------------------------
2a. Multiple triangles in one sequential vertex list and one draw call.
2b. Build a rectangle from two triangles with drawArrays.
2c. Store rectangle corners once and render them with an index buffer.
2d. Build a letter F from indexed triangles to practice vertex reuse.

CHAPTER 3 — PRIMITIVE TOPOLOGIES
--------------------------------
3a. POINTS: render independent point positions.
3b. LINES: pair vertices into independent line segments.
3c. LINE_STRIP: connect adjacent vertices without closing the path.
3d. LINE_LOOP: connect and close the path.
3e. Construct a hexagon outline using line-loop topology.
3f. TRIANGLES: assemble independent groups of three vertices.
3g. TRIANGLE_STRIP: extend connected triangles while reusing vertices.
3h. TRIANGLE_FAN: fill a polygon around a shared center.

CHAPTER 4 — DYNAMIC BUFFERS
---------------------------
4a. Change triangle vertex positions through GUI state and dynamic buffer data.
4b. Apply the same editable-geometry idea to a rectangle.
4c. Generate an editable polygon/circle outline with LINE_LOOP.
4d. Generate an editable filled polygon/circle with TRIANGLE_FAN.

CHAPTER 5 — VERTEX DATA AND COLOR
---------------------------------
5a. Send vertex colors through shader varyings and observe interpolation.
5b. Keep position and color in separate attribute buffers.
5c. Interleave position and color in one buffer; configure stride and offsets.
5d. Color two rectangle triangles independently at their vertices to produce
	interpolated gradients across the shape.
5e. Give each triangle its own uniform per-triangle vertex color, repeating
	shared corner positions when the colors differ.

CHAPTER 6 — UNIFORMS
--------------------
6a. Control brightness with one float uniform.
6b. Pass RGB as separate float uniforms and control brightness.
6c. Pack RGB into a vec3 uniform with brightness as a separate float.
6d. Combine vertex-varying color and uniform color in one shader flow.
6e. Survey the uniform types and WebGL upload calls used by the example.

CHAPTER 7 — MULTIPLE OBJECTS
----------------------------
7a. Draw a triangle and rectangle with separate VAO/VBO state and one shader.
7b. Draw objects with different primitive topologies using the same shader.
7c. Switch between a uniform-color program and a vertex-color program.
7d. Combine a line grid and triangle in clip space with separate draw calls.

CHAPTER 8 — PIXEL SPACE AND WORLD GEOMETRY
------------------------------------------
8a. Define a rectangle in pixel units and map it to clip space.
8b. Move pixel-to-clip conversion into a mat3 uniform and invert screen Y.
8c. Generate random rectangles and reuse/update the same vertex buffer.
8d. Add a large grid and rectangle in pixel-space coordinates.
8e. Add X/Y axes and multiple objects under the same projection.

CHAPTER 9 — 2D CAMERA
---------------------
9a. Establish a large world grid, axes, and drawable objects.
9b. Represent camera position as JavaScript state and send it to the shader.
9c. Add camera zoom and discrete controls.
9d. Encapsulate camera translation/zoom in a view matrix.
9e. Add key-state-driven discrete camera movement alongside GUI controls.
9f. Update movement continuously while keys are held using a render loop.

CHAPTER 10 — 2D OBJECT TRANSFORMATIONS
--------------------------------------
10a. Translate object vertices with uniform values.
10b. Add object rotation to the translated scene.
10c. Add independent X/Y scale values.
10d. Compose translation, rotation, and scale into a model matrix.

CHAPTER 11 — 2D ROTATION
------------------------
11a. Rotate an object with sine and cosine.
11b. Represent rotation with a matrix.
11c. Compare the results of changing translation/rotation order.
11d. Rotate around and visualize a pivot.

CHAPTER 12 — 2D SCALE
---------------------
12a. Apply uniform scale directly to vertex coordinates.
12b. Use a scale matrix for uniform and non-uniform scaling.

CHAPTER 13 — MODEL MATRICES
---------------------------
13a. Compose translation, rotation, and scale in the shader.
13b. Build a model matrix in JavaScript and pass it as a uniform.
13c. Give multiple objects independent model matrices.
13d. Compose model, view, and projection transforms across a scene.

The file-by-file path, implementation detail, and source-header caveats are in
chapters_index.txt.

SERIES RELATIONSHIP
===================

CG Fundamentals is the conceptual, visual series; WebGL Fundamentals is the
implementation series. A reusable resource should flow from the concept to
both episodes:

CG concept → master diagram/animation → CG Fundamentals explanation →
WebGL Fundamentals implementation.

Core conceptual subjects include the GPU, shaders, rasterization, vertices,
vectors, matrices, coordinate spaces, cameras, projection, textures, UVs,
depth, normals, lighting, materials, and the rendering pipeline. Keep those
conceptual episodes API-independent; introduce WebGL calls in the coding
series.
