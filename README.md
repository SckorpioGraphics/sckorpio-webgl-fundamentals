# Sckorpio Graphics: WebGL Fundamentals

A hands-on WebGL 2 course with 50 numbered lessons across Chapters 1–10 and two extra experiments.

Start with the [quick guide](Documentation/QUICK_START.md). For lesson-by-lesson coverage, see the [chapter index](Documentation/chapters_index.txt); the [series plan](Documentation/series_episodes.txt) separates implemented lessons from future topics.

To run the current demo, serve this folder over HTTP:

```sh
python3 -m http.server 8000
```

Open `http://localhost:8000`. The page currently loads `chapters/chapter09/chapter9f.js`.
